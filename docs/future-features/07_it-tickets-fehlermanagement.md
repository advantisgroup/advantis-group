# IT tickets & Fehlermanagement

Ideas for the internal support (`/it-tickets`) and corrective-action
(`/fehlermanagement`) workflows.

- **SLA timers with escalation** — flag and notify admins when a ticket
  breaches its expected response/resolution time.
- **Ticket categories with saved filters** — persist named filter
  combinations per user for repeat triage.
- **Knowledge-base suggestions on ticket creation** — surface a matching
  guidebook ("did you mean this guide?") using the wiki-chat embeddings
  before a ticket is filed.
- **Error trend dashboard** — a recurring-category view over time built on
  `errorCategories`/`errorMeasures`, complementing the existing
  "problem-pattern view" idea.
