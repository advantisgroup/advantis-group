# New domains

Ideas that don't extend an existing module but would be net-new areas of
the intranet. `intranet-management-feature-ideas.md` deliberately avoids
generic "employee engagement" features and a generic task platform — these
should be weighed against that bar before being taken on, since each one
starts a new source of truth rather than reusing an existing one.

- **Recognition/kudos** — a peer-to-peer shoutout feed, surfaced through
  announcements/notifications.
- **Meeting room / resource booking** — booking for desks, rooms, and
  equipment, integrated with the calendar.
- **Employee pulse surveys** — a lightweight recurring anonymous check-in
  question with aggregate results.
- **Asset/equipment tracking** — who currently holds which laptop/monitor,
  useful as an input to the offboarding checklist.
- **Unified company search ("Spotlight")** — one search surface across
  directory, wiki, guidebooks, tickets, and chat, exposed through the
  existing `CommandPalette`.
