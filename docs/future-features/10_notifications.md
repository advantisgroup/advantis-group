# Notifications

Ideas for making notifications more targeted and less of a firehose,
building on the existing "actionable notification grouping" idea already
tracked in `intranet-management-feature-ideas.md`.

- **Per-category preferences** — let users choose in-app vs email vs digest
  per notification kind, building on `notification-kinds.ts`.
- **Digest email** — an opt-in daily/weekly rollup instead of one email per
  event.
- **Browser push notifications** — Web Push for a small set of genuinely
  urgent categories.
