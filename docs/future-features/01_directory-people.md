# Directory & people

Ideas for making the directory more than a flat employee list — surfacing
org structure, skills, and team availability that already exist in the data
but aren't visualized yet.

- **Org chart view** — a visual reporting-line tree built from
  `departments`/`users`, instead of only a flat/filterable list.
- **Skills/expertise tags** — searchable tags on profiles so people can find
  "who knows X".
- **Team "back when" mini-calendar** — extend the existing "out today" badge
  into a short-range view of when absent teammates return.
- **Birthday/anniversary widget** — opt-in dashboard widget for upcoming
  personal dates.
- **Profile completeness nudges** — prompts for missing photo, skills, team,
  etc. (related to the profile completeness helper already noted in
  `intranet-management-feature-ideas.md`).
